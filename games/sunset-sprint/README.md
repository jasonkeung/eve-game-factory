# Sunset Sprint

Thread a red roadster through desert-highway traffic before the clock runs
out. Original arcade road racer: three 15-second checkpoint legs, three lives,
boost with a cooldown, fuel cans that refill a little time.

- Arrows/WASD: steer, move along the road, and change speed
- Z/Space: boost (recharges after use)
- X: brake
- Enter: start / restart, Esc: pause

Built on `@games/kit` (Kaplay, 320x180, Sweetie-16, ZzFX).
